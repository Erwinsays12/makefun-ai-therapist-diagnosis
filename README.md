Entry for the [Your AI Therapist's Diagnosis](https://make.fun/c/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41) competition on make.fun.

## What it does

`main.ts` writes one single-line diagnosis — the funniest line an AI therapist
hands its human — to `/output/entry.txt`:

> Diagnosis: severe doomscrolling-induced empathy fatigue. Prescription: touch
> grass, then log the grass in a spreadsheet.

The line was picked by an internal head-to-head tournament over 12 candidate
diagnoses, judged against the competition's own rubric: a real diagnosis in a
therapist's calm clinical voice, with the laugh landing at the very end.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Deterministic: no clock, no network, no randomness — the same 120-character
line on every run, well inside the 200-character limit.
